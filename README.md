# Steam-game

3초 전의 나를 그대로 따라 하는 그림자 분신과 함께 싸우는 2D 횡스크롤 액션 로그라이크입니다.

- 엔진: Unity (2D)
- 플랫폼: PC (Steam)
- 상태: 그림자 분신 전투 프로토타입

## 계획

1. 컨셉 확정
2. 핵심 루프 프로토타입 (그림자 분신 전투부터)
3. 스팀 상점 페이지와 데모
4. 콘텐츠 확장, 다듬기, 출시

## 프로토타입 실행 방법

1. Unity Hub에서 이 폴더를 열고 `Assets/Scenes/SampleScene`을 연다.
2. Play를 누른다. 스테이지, 플레이어, 분신, 적이 코드로 만들어진다. 씬을 따로 손댈 필요가 없다.

| 동작 | 키보드와 마우스 | 컨트롤러 |
| --- | --- | --- |
| 이동 | A/D 또는 방향키 | 왼쪽 스틱, 십자키 |
| 점프 | Space | 아래 버튼 |
| 공격 | J, Z 또는 마우스 왼쪽 | 왼쪽 버튼 |
| 대시 (무적) | 왼쪽 Shift, L 또는 C | 오른쪽 버튼, RB |
| 분신과 자리 바꾸기 | K, X 또는 마우스 오른쪽 | 위 버튼 |
| 강화 고르기 | 1, 2, 3 또는 클릭 | 십자키 왼쪽, 위, 오른쪽 |
| 다시 시작 | R | |

### 진행

- 스테이지는 가로로 길고, 평지, 계단, 구덩이, 언덕, 탑, 섬 구간이 무작위 순서로 이어진다. 스테이지 번호가 오를수록 길어지고 적 체력이 늘어난다.
- 적을 모두 잡으면 오른쪽 끝의 문이 초록색으로 열린다. 문에 닿으면 체력을 2 회복하고 강화 3개 중 하나를 고른 뒤 다음 스테이지로 간다.
- 구덩이에 빠지면 체력을 1 잃고 마지막으로 서 있던 땅으로 돌아간다.
- 체력이 0이 되면 1스테이지부터 다시 시작하고 강화는 사라진다.

### 전투

- 분신은 3초 전의 내 행동을 따라 한다. 본체와 분신이 0.35초 안에 같은 적을 때리면 협공으로 피해가 두 배가 된다.
- 빨간 적(돌진형)은 다가와서 노랗게 깜빡인 뒤 돌진한다. 돌진이 끝나면 어두워지며 잠깐 빈틈이 생긴다.
- 주황 적(원거리형)은 노랗게 깜빡인 뒤 탄을 쏜다. 탄은 대시로 통과할 수 있다.
- 적은 깜빡이는 동안과 공격 중에는 맞아도 밀려나지 않는다.
- 1스테이지 시작 지점의 허수아비는 연습용이다.

코드는 `Assets/Scripts/Prototype`에 있다. 시작 수치는 `RunStats.cs`, 강화 목록은 `Upgrades.cs`, 스테이지 구간은 `StageBuilder.cs`, 적의 속도와 타이밍은 `Enemy.cs` 위쪽에서 바꿀 수 있다.
