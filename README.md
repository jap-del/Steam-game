# Steam-game

3초 전의 나를 그대로 따라 하는 그림자 분신과 함께 싸우는 2D 횡스크롤 액션 로그라이크입니다.

- 엔진: Unity (2D)
- 플랫폼: PC (Steam)
- 상태: 그림자 분신 전투 프로토타입

## 계획

1. 컨셉 확정
2. 핵심 루프 프로토타입 (그림자 분신 전투부터)
3. 스팀 상점 페이지와 데모
4. 콘텐츠 확장, 다듬기, 출시

## 프로토타입 실행 방법

1. Unity Hub에서 이 폴더를 열고 `Assets/Scenes/SampleScene`을 연다.
2. Play를 누른다. 전투장, 플레이어, 분신, 적이 코드로 만들어진다. 씬을 따로 손댈 필요가 없다.

| 동작 | 키보드와 마우스 | 컨트롤러 |
| --- | --- | --- |
| 이동 | A/D 또는 방향키 | 왼쪽 스틱, 십자키 |
| 점프 | Space | 아래 버튼 |
| 공격 | J, Z 또는 마우스 왼쪽 | 왼쪽 버튼 |
| 분신과 자리 바꾸기 | K, X 또는 마우스 오른쪽 | 위 버튼 |
| 대시 (무적) | 왼쪽 Shift, L 또는 C | 오른쪽 버튼, RB |
| 강화 고르기 | 1, 2, 3 또는 클릭 | 십자키 왼쪽, 위, 오른쪽 |
| 다시 시작 | R | |

분신은 시작 3초 뒤에 나타나 3초 전의 내 행동을 따라 한다. 본체와 분신이 0.35초 안에 같은 적을 때리면 협공으로 피해가 두 배가 된다. 왼쪽 끝의 허수아비는 연습용이다.

웨이브의 적을 모두 잡으면 강화 3개 중 하나를 고른다. 강화는 죽거나 R로 다시 시작하면 사라진다.

코드는 `Assets/Scripts/Prototype`에 있고, 시작 수치(지연 시간, 피해량, 대기시간)는 `RunStats.cs`에서, 강화 목록은 `Upgrades.cs`에서 바꿀 수 있다.

## 개발 환경

Unity 프로젝트는 이 저장소의 최상위 폴더에 둡니다. `Assets/`, `Packages/`, `ProjectSettings/` 폴더가 저장소 루트에 바로 오도록 만들어 주세요.
